# QuoteForge

Modern Rails quote generator for **Tech**, **Startup**, and **Coding** quotes. Remembers which quotes you have already seen in this browser session.

## Setup

```bash
bin/setup
bin/rails db:seed
```

## Run

```bash
bin/dev
```

Then open [http://127.0.0.1:3000](http://127.0.0.1:3000).

If `foreman` is unavailable, `bin/dev` starts Rails alone — run `bin/rails tailwindcss:watch` in a second terminal while editing styles.
